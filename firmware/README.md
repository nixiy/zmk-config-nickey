# Firmware releases

Nickey44の書き込み済みファームウェアを、セマンティックバージョニングに基づいて管理しています。

新規セットアップや通常の更新には、ZMK v0.4.0（Zephyr 4.1.0ベース）へ更新した最新の `v2.0.0` を推奨します。
`v1.x` はZMK v0.3.0をベースにした旧バージョンです。

## バージョン一覧

| ファームウェア | ZMK | リリース日 | 内容 |
| --- | --- | --- | --- |
| [v1.0.0](v1.0.0/) | v0.3.0 | 2026-04-04 | 標準ファームウェア |
| [v1.1.0](v1.1.0/) | v0.3.0 | 2026-08-18 | ZMK Studio対応を追加 |
| [v2.0.0](v2.0.0/) | v0.4.0 | 2026-08-25 | Zephyr 4.1.0へ更新、DYA Studio向け機能を追加 |

左右で異なるバージョンを混在させず、必ず同じバージョンのフォルダ内にあるファームウェアを両側へ書き込んでください。特にZMK v0.3.0ベースの `v1.x` からZMK v0.4.0ベースの `v2.0.0` へ更新する際は、左右をまとめて更新してください。

## ファイルの選び方

各バージョンのフォルダには、次の3ファイルがあります。

- `nickey_l.uf2`: 左手側用
- `nickey_r.uf2`: 右手側用
- `settings_reset.uf2`: 設定リセット用

通常の更新では、左手側用と右手側用をそれぞれ対応する側へ書き込みます。接続やペアリングに問題がある場合のみ、両側へ設定リセット用ファームウェアを書き込んでから、改めて左右のファームウェアを書き込んでください。

## バージョン番号

バージョン番号は`MAJOR.MINOR.PATCH`形式です。

- `MAJOR`: 互換性に影響する大きな変更
- `MINOR`: 後方互換性のある機能追加
- `PATCH`: 不具合修正などの小さな変更
