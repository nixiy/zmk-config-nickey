# Firmware releases

Nickey44の書き込み済みファームウェアを、セマンティックバージョニングに基づいて管理しています。
このブランチに収録しているファームウェアは、いずれもZMK 3系をベースにしています。

## バージョン一覧

| バージョン | リリース日 | 内容 |
| --- | --- | --- |
| [v1.0.0](v1.0.0/) | 2026-04-04 | 標準ファームウェア |
| [v1.1.0](v1.1.0/) | 2026-08-18 | ZMK Studio対応を追加 |

ZMK Studioを利用する場合は`v1.1.0`を使用してください。左右で異なるバージョンを混在させず、同じフォルダ内のファームウェアを両側へ書き込んでください。

## ファイルの選び方

各バージョンのフォルダには、次の3ファイルがあります。

- `nickey_l rgbled_adapter-seeeduino_xiao_ble-zmk.uf2`: 左手側用
- `nickey_r rgbled_adapter-seeeduino_xiao_ble-zmk.uf2`: 右手側用
- `settings_reset-seeeduino_xiao_ble-zmk.uf2`: 設定リセット用

通常の更新では、左手側用と右手側用をそれぞれ対応する側へ書き込みます。接続やペアリングに問題がある場合のみ、両側へ設定リセット用ファームウェアを書き込んでから、改めて左右のファームウェアを書き込んでください。

## バージョン番号

バージョン番号は`MAJOR.MINOR.PATCH`形式です。

- `MAJOR`: 互換性に影響する大きな変更
- `MINOR`: 後方互換性のある機能追加
- `PATCH`: 不具合修正などの小さな変更
